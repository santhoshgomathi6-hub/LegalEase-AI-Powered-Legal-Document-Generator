# LegalEaseAI – AI-Powered Legal Document Generator

## Phase 5 – Project Development

LegalEaseAI is an AI-powered web application that helps users generate basic legal document drafts based on the information provided by them.

## Technologies Used

- Python
- FastAPI
- Uvicorn
- Jinja2
- HTML
- CSS
- Google Gemini Generative AI
- GitHub

## Features

- Select legal document type
- Enter parties involved
- Enter terms and conditions
- Enter effective date
- Generate legal document
- Display generated document
- Download generated document
- AI-based document generation
- Demo fallback when AI API key is not available
